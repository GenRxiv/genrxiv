# GenRxiv

An open archive for AI-generated research.

GenRxiv is a preprint server for research that was substantially generated or
co-generated by AI. Submissions are accepted in LaTeX or Markdown, authors are
identified by ORCID iD, and everything is openly licensed and readable by both
people and machines.

**Status: pre-launch.** The archive is being built in the open. It is not yet
accepting submissions.

---

## Why

Preprint servers exist for most fields — arXiv for physics and maths, bioRxiv
for biology, ChemRxiv for chemistry. None were designed with AI-generated work
in mind, and most are still working out what to do about it.

GenRxiv starts from the other end. It assumes AI involvement and asks authors
to disclose it plainly, so the work can be read, cited, and evaluated with that
context in the open rather than guessed at.

GenRxiv is not peer-reviewed and does not evaluate the scientific quality of
submissions.

## How it works

| | |
|---|---|
| **Submissions** | LaTeX or Markdown, rendered server-side to PDF and HTML |
| **Author identity** | ORCID iD, so attribution is verifiable |
| **Disclosure** | Every paper carries a statement of what was AI-generated and how |
| **Machine access** | OAI-PMH metadata endpoint, sitemap, and schema.org JSON-LD |
| **Licensing** | Open access, Creative Commons |

## Architecture

GenRxiv is built on [Open Journal Systems](https://pkp.sfu.ca/software/ojs/)
rather than from scratch — OJS already handles submission workflow, versioning,
moderation, ORCID login, and OAI-PMH.

```
                    Cloudflare Tunnel
                           |
        +------------------+------------------+
        |                                     |
    OJS (submissions, metadata, ORCID)   Static site
        |
        +-- PostgreSQL
        |
        +-- convert-service  (LaTeX -> PDF via Tectonic)
                             (Markdown -> PDF)
```

The conversion service runs untrusted author-submitted LaTeX, so it is
sandboxed: no shell-escape, per-job scratch directories, hard wall-clock
timeouts, capped CPU and memory, and no published ports.

## Running it locally

Requires Docker and Docker Compose.

```bash
git clone https://github.com/<org>/genrxiv.git
cd genrxiv/deploy
cp .env.example .env    # fill in your own values
docker compose up -d
```

See [docs/SETUP.md](docs/SETUP.md) for the full walkthrough, including
Cloudflare Tunnel, ORCID registration, and backups.
